# glyph-forge (app) — agent instructions

Internal audit UI. Consumes static SVGs + a manifest JSON generated by `@glide/glyph-forge-engine`. Does not hit the filesystem at request time — everything lives in `public/`.

## Run

```bash
npm run forge:build                             # from repo root — regen cache
turbo dev --filter=@glide/glyph-forge           # https://forge.localhost
```

Dev server is fronted by **portless** (global install) — `portless forge next dev` proxies `https://forge.localhost` onto a random port in 4000-4999. Marketing site uses `https://glide.localhost` via the same mechanism. No port collisions.

`predev` and `prebuild` run `scripts/sync-cache.ts`, which mirrors `packages/glyph-forge/public-cache/svg/` and `packages/glyph-forge/manifests/broken-glyphs.json` into `public/`. Both are `.gitignore`d.

## Routes

- `/` — glyph grid (filter bar: family, feature, verdict, free-text)
- `/g/[family]/[name]` — loupe view: 2×8 weight strip, overlay toggle, sidebar

## Conventions

- **No shadcn / no base-ui / no blode-icons** here. This is an internal tool — keep the dep graph small. Use plain Tailwind + the `cn()` utility in `lib/utils.ts`.
- **Server components by default**. The manifest JSON is loaded server-side via `lib/data.ts`; client components are opt-in (`"use client"`) for interactivity only (filters, overlay toggle).
- **SVG cells are plain `<img>` tags**. They're small, cacheable, and let the browser do lazy loading for free.
- **Route param encoding**: glyph names containing `.` and `_` are safe in URLs; `/` in glyph names (there are none now, but defensive) should be encoded.

## Gotchas

- **Don't commit `public/svg/` or `public/broken-glyphs.json`** — generated, gitignored.
- **Port 3333** not 3000 — so it coexists with `apps/web` on 3000 during `turbo dev` at the root.
- **Missing SVGs render as broken images on purpose**: if a glyph doesn't exist in one of the 16 cells (e.g., the donor lacks `.ss02` variants), the cell shows a dim placeholder. This is a real audit signal, not a bug.
- **Portless cert lives in the system trust store**: if `https://forge.localhost` throws a cert error, run `portless trust` once. Safari needs `portless hosts sync` for `/etc/hosts` resolution.

## Do-not

- Do not add analytics, telemetry, or any third-party script. Internal tool.
- Do not read from `packages/variable-gen/` at runtime; all its data flows through the `glyph-forge-engine` manifest.
- Do not import directly from `packages/glyph-forge/` via relative paths. Use the `@glide/glyph-forge-engine` workspace package for typed imports.
